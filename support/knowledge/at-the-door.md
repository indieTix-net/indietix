# At the door

## The ticket scanner
- Any phone, tablet or laptop with a camera works: log in and open **Ticket Scanner**. No app to install. It picks the rear camera on phones.
- **Auto Check-in** checks a valid ticket in the moment it's scanned. **Sound** plays a tone on each scan.
- Scanning a ticket twice shows "already checked in", not an error. Refunded, cancelled and transferred tickets are refused.
- **The camera won't start?** Allow camera access for the site in the browser, make sure no other app is using the camera, and reload the page. On iPhone, use Safari or Chrome and check Settings → the browser → Camera.
- **A USB or Bluetooth handheld scanner** also works: use the Manual Check-in search box, since most handheld scanners type like a keyboard.

## Manual check-in
Look up a ticket by name, email or code on **Manual Checkin / List Tickets** when a code won't scan.

## Extra staff on a busy night
Create a staff account in User Management (new accounts can only check people in) and log in on another phone.

## Skeleton keys
Reusable QR codes for comps, re-entry or staff, set up in Client Settings. Each can have limits (uses per day, total uses, an expiry date). Every use is logged.

## Printing paper ticket stubs (optional)
- Uses a Brother QL-series network label printer at the box office and a small print agent running on a computer on the same network.
- Then **Print Ticket** on a ticket, **Print Tickets** on an order (prints every valid ticket on it), or **Confirm Check-in & Print** at the door.
- **Prints failing or "connection timed out"?** Turn the printer off and on, make sure it's on the network, and check only one copy of the print agent is running. Setting printing up the first time: a person from IndieTix helps with that.

## Today's Dashboard
A live view of today's showtimes and check-ins, for whoever's running the door.
