# Getting started

## Signing up (hosted IndieTix)
1. On the signup page, enter the venue's name and contact details, and optionally pick a web address (yourvenue.indietix.net).
2. Sign in with Square using the venue's Square account and approve IndieTix's access.
3. About a minute later the box office is ready, and a welcome email arrives with the venue's **Client ID** and a link to set the password.

The Client ID and the main login's username are the same.

## Logging in
- The login page needs three things: Client ID, username and password. On the venue's own web address the Client ID is filled in already.
- **Forgot your password?** Staff accounts can use "Forgot password" on the login page.
- **Lost the venue's main (client) login password?** Email support from the venue's contact address; IndieTix resets it after checking it's really the venue.
- Changes to a staff account's permissions take effect the next time that person logs in. A login lasts up to 24 hours.

## Staff accounts
- The venue's main login (the "client" login) can do everything. Add staff under **User Management**.
- A new staff account can only check people in at the door until you give it more. The options: view, edit, check-in, marketing and admin (Insights).
- Client Settings, User Management, Skeleton Keys and API Keys are only available to the main login.
- A staff account can be limited to certain events (for example a promoter who should only see their own show's sales), using filters on the User Management page.

## Setting things up after signup
In **Client Settings** (main login): branding and logo, the sender email for tickets, the venue's legal details for its terms and privacy pages, Google Calendar, social media accounts, report destinations, and more. Movie lookups need a free OMDB API key from omdbapi.com.
