# About IndieTix

IndieTix is ticketing for independent cinemas and venues, built on Square. It started as the box office for Liberty Hall in Lawrence, Kansas, and grew into a full platform.

- **Square handles the sale.** Tickets are Square items, sold at the venue's register and on its Square Online store. IndieTix never handles card details.
- **IndieTix handles everything around the sale:** QR-code tickets by email (and by text, if the venue has texting set up), a door scanner that runs on any phone, tablet or laptop, order management (refunds, resends, transfers), box-office reports, and a marketing scheduler for email, Facebook, Instagram and TikTok.
- **No per-ticket fees to ticket buyers.** IndieTix doesn't add a fee to each ticket.
- **Each venue is fully separate:** its own database, storage and settings. One venue can never see another's data.
- **Free and open source.** The code is public at https://github.com/indieTix-net/indietix under the AGPL license; anyone can run it on their own AWS account. Hosted IndieTix is the same software, run for the venue, for a monthly fee.
- **Who's behind it:** Wolffebrothers LLC.
